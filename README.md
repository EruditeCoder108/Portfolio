## ⚡ Core Engineering Philosophy

This repository is built without heavy UI frameworks (no React, no Next.js, no bundler overhead) to demonstrate uncompromising frontend engineering and GPU rendering discipline:

- **Zero-Reflow GPU Pointer & Parallax Engine**: Single unified 120 FPS `requestAnimationFrame` loop utilizing hardware-accelerated `translate3d()` and `rotateX/rotateY` transforms. Zero layout thrashing or synchronous reflows in mouse/scroll event paths.
- **Web Audio API Procedural Synthesizer**: Custom procedural sound generator synthesizing high-transient clicks, rising chords, and glass arpeggios in real-time without fetching external audio assets. Defaulted to opt-in for professional environments.
- **Mobile Compositing Discipline**: Scoped `@media (max-width: 640px)` pipeline removing expensive backdrop blur compositing, hiding off-screen particle layers, and eliminating battery drain on mobile GPUs.
- **Accessible & Privacy-Compliant**: Keyboard navigable, respectful of `prefers-reduced-motion` and `visibilitychange` background tab throttling, and includes a full [Google Play & GDPR Compliant Privacy Policy](privacy.html).
